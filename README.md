# Web Development Fundamentals: HTML & CSS

This repository contains my personal collection of code exercises, layout practice, and quizzes completed while learning frontend web development.
📂 Repository Structure
1. HTML/: Semantic tags, tables, forms, inputs, and inline vs. block elements.
2. CSS/: Box model, display properties, sizing units, typography, and color styling.
3. QUIZ/: Self-assessment HTML/CSS quizzes and mini-practice tasks.

🚀 How to Run
1. Clone or download this repository:
git clone [https://github.com/mehulsinghushwah74-sys/Web-Dev-Journey.git](https://github.com/mehulsinghushwah74-sys/Web-Dev-Journey.git)
2. Open any .html file directly in your preferred web browser, or use the Live Server extension in VS Code.
